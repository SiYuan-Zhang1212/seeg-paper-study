# SEEG 文献追问清单

整理第 4–7 步时逐条对照。问不出来 / 论文没写 / 代码没公开的，直接写"未说明"或"未公开"，不要留空、不要用领域惯例补。

## 被试与任务设计

- 总 N 与进入分析的 N；病因（耐药癫痫）、入组与排除标准
- 电极：型号、触点间距、植入脑区及各区人数；单侧/双侧；哪些触点进入分析
- 任务：条件与水平、每被试 trial 数、几天、block 结构、练习/正式、条件平衡方式
- 时间轴：**t=0 是哪个事件**、每个事件的相对时刻与时长、有无 jitter、反馈
- 触发码：字符/数值码，如何写进数据、如何与 iEEG 对齐
- 行为：RT、正确率、剔除标准、学习/练习效应及其统计量
- 任务脚本位置：`file:line`

## 数据收集

- 采集设备与记录软件、采样率、在线滤波
- 参考：白质 / 双极 / 平均参考 / 耳垂；是否离线重参考
- 电极定位：CT+MRI 配准流程、软件（Fieldtrip / Lead-DBS / FreeSurfer / 3D Slicer…）、坐标空间（native / MNI）、是否人工复核
- 事件对齐：TTL / 光电 / 音频通道，延迟校正
- 行为数据：格式、字段、文件命名
- 数据文件清单：连续数据 / 分段数据 / 行为 / 定位，各自的命名规则
- 公开范围：仓库 README 的原话，哪些公开、哪些因体积或隐私不公开

## 预处理

- 读入格式（EDF / NSx / BrainVision / .mat）与工具（EEGLAB `pop_biosig` 等）
- 滤波：高通、低通、notch 的具体数值
- 坏道 / 坏段判定标准
- 癫痫样活动（spike / 高频活动）剔除：算法、阈值、剔除比例 —— SEEG 特有，务必找到
- ICA / 伪迹回归 / 坏道插值
- 重参考方式
- 重采样
- 分段：epoch 窗、基线窗、t=0 对齐
- 归一化：z-score 沿哪个维度、基线窗口、是否分条件
- 输出几套数据集，分别给哪个分析

## 时频 / HFB

- 方法：Morlet 小波 / Welch / Hilbert；cycles 范围、频点分布（log 还是线性）
- 频段定义（如 theta 4–8 Hz、HFB 60–100 Hz），是否按被试个体化
- 单 trial 还是 trial 平均
- 基线校正：窗口、减除还是相除、early/late 是否分别做
- 统计：cluster permutation 的阈值、置换次数、单/双尾

## 解码 / MVPA

- 分类器（SVM / LDA）、核、一 vs 一 / 一 vs 全（`fitcecoc` 等）
- 交叉验证折数、是否折内平均成 super-trial、重复次数
- 特征：电极、时间点、频段的选择依据
- chance level 怎么算、类别是否平衡
- 置换检验实现方式：**重跑分类器** 还是 **打乱已保存的预测值**（两者不等价，必须写清代码实际做法）

## 表征相似性 / IEM / 连通性

- 模型与基函数（如 half-sine^7 IEM 通道数、调谐角度）
- 训练/测试划分与样本量
- 指标（CTF slope、相关系数、KL 散度…）与提取窗口
- 跨被试聚合：随机伪被试、leave-one-out、jackknife

## Ripple / 高频振荡

- 频段、检测阈值（±SD）、持续时间下限、对采样率的要求
- rate 的计算分母（trial 数 × 窗口秒数）
- 与任务事件的锁定方式

## 统计

- 置换次数、cluster 定义（相邻时间点）、cluster 统计量（如 t 值求和）
- 多重比较校正方法、阈值
- 单尾 / 双尾、自由度、效应量
- 显著性时间窗（论文报告的 ms 范围）能否在代码里找到对应

## 复现边界

- 仓库里**没有**哪些关键步骤（写进"未公开"表）
- README 明确声明的限制（数据不全、需联系作者等）
- 依赖的 toolbox 与版本、MATLAB 版本
- 硬编码路径、需要手改的变量
- 跑通顺序与中间产物
